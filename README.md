# the-liva.com

The Liva tanıtım sitesi. Saf HTML/CSS/JS, derleme adımı yok. GitHub Pages ile yayınlanır.

- Ürünler: `assets/js/products.js` (en fazla 5 ürün, TR ve EN metinleriyle)
- Ürün görselleri: `assets/img/products/<ürün-id>/`
- Arayüz metinleri (TR/EN): `assets/js/main.js` içindeki `T` nesnesi
- Alan adı: `CNAME`

Önemli: `ai-yz-panel.the-liva.com` DNS kaydı başka bir sistem tarafından kullanılıyor, değiştirmeyin.
